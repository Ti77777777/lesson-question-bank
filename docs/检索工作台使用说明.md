# 检索工作台

更新日期：2026-10-27

## 找题顺序

1. 输入学校、考试名称、题面或答案中的关键词；停止输入约 0.4 秒或按回车即检索。
2. 选择来源类别、适用年级、题型、思维难度。题型可多选，同一行按“或”匹配；不同条件之间按“且”匹配。
3. 在“定位试卷”中选择年份、地区／卷别和完整卷名。两所测试学校的试卷分别保留独立入口。
4. 在左侧“知识点与方法”中按类别和主题直接勾选标签，即时筛选右侧题目；标签匹配方式也在侧栏切换。窄窗口时展开页内标签区域即可使用。
5. 结果可直接加入选题篮；“已选条件”中的每个条件均可单独移除，也可一次清空。刷新或复制当前页面链接会保留条件。

切换来源类别会清除原来的年份、地区和具体试卷，并保留年级；切换年级、年份或地区会清除具体试卷选择。清空条件保留结果排序。年级筛选随链接保存，重新打开链接可恢复。

## 筛选信息的含义

- **来源类别**：固定提供高考真题、模拟考、学科竞赛、月考试卷、期中考、期末考、开学考、阶段测试、其他试卷。暂无题目的类别也保留入口，选中后显示真实的空结果；教材、教辅等类别按已有资料显示。优先使用已保存的考试类别，其次根据来源卷名和导入备注识别。
- **适用年级**：提供高一、高二、高三、未标注。优先使用已保存年级；未指定时从来源卷名识别，高考真题和明确的普通高中毕业班试卷归高三。仅有“2027届”而没有学段或年级证据时不猜测；混合年级资料不强行指定一个年级。这里是来源试卷的年级，题目涉及的知识点仍由标签筛选。
- **年份**：优先读取来源的版次，其次读取来源名称中的年份；跨学年试卷归入学年起始年，例如 2026～2027 学年归入 2026。没有明确年份时归入“未标注”。
- **地区／卷别**：使用已保存的来源字段。历史资料中该字段也保存“新高考I”“全国I”等卷别，因此不将它们误称为地理地区。未保存的地区不根据文件名猜测。
- **思维难度**：使用已有 1–5 级评分。基础为 1–2，常规为 3，进阶为 4–5。未标注题目单列；指定评分区间时不包含未标注题目。计算、综合难度上限可在“更多条件”中设置。
- **标签匹配**：同时检查题目标签与当前版本解法的标签；历史版本独有的解法标签不参与检索。“同时包含”要求所有所选标签均命中，“任一包含”命中一个即可，“排除”移除带有所选任一标签的题目。
- **仅看审校通过**：沿用系统现有审校判断，与“是否有答案”并不等同。

来源类别、年级、年份和地区组合必须由题目的同一个出处满足；多出处题目不会把一份试卷的年级与另一份试卷的类别拼接匹配。

在 AI 工作台展开“试卷来源”，可一起保存来源名称、考试类别、年级。明确保存的类别和年级优先于自动识别，后续修改卷名不会使其丢失；选择“按卷名识别”可清除手工指定。此次将 SRC000028 保存为“模拟考 / 高三”，原文件和题目内容不变。

## 题目纠错入口

每道结果右侧可点击“纠错”，登记问题类型、问题说明和修改建议，也可进入题目修改。结果区支持“仅看待纠错”，可与原有条件组合。题目详情的“纠错与处理记录”可跟进修正、无需修改和重新打开，完整保留处理过程。详见 [题目纠错使用说明](题目纠错使用说明.md)。

## 开发接口补充

- `GET /api/search/catalog`：返回正式在用题目的来源目录、类别和 `grades`；每个来源含 `category`、`grade`、`year`、`region`、去重题目数 `count`。考试类别固定返回，数量可为 0。
- `GET /api/questions` 支持 `source_category`、`source_grade`、`source_year`、`source_region`、`think_unrated=1`。年级编码为 `senior1`、`senior2`、`senior3`；空值用 `_unknown` 筛选。原有 `source_id` 继续支持。
- `POST /api/sources` 和 `PATCH /api/sources/{id}` 支持 `exam_type`、`grade`；无效值返回 400，空值清除手动指定。旧库启动时补齐这两个可空字段。
- 难度仅接受 1–5；下限大于上限或同时指定“未标注”和思维难度区间时返回 400。
- 检索页有请求序号检查，快速连续切换条件时丢弃过时结果；分页仅追加当前条件对应的题目。
