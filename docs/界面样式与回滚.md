# 界面样式与回滚

## 本次调整（v0.4.3）

- 页面使用统一的无衬线界面字体、蓝绿色强调色及浅灰绿背景。审校状态和错误提示继续保留各自的语义颜色。
- 筛选选项与独立多选框对齐，减少重复边框与间距；侧栏说明提高可读性。
- 题目卡片提供完整的题面宽度，来源与标签置于题面下方，难度、使用记录和操作集中在卡片底部。
- 排版工具、表单和按钮沿用同一视觉风格。纸面保留衬线字体，数学公式继续使用数学字体。

此次调整仅涉及页面样式和样式表加载，不变更后端接口、数据库、题目内容或正式讲义的排版模板。桌面和窄屏可使用相同功能。

## 样式组织

`app/static/polish.css` 在基础样式、排版样式和编辑体验样式之后加载，用于集中维护屏幕视觉。纸面尺寸、分页和公式字体继续由原模块管理。
