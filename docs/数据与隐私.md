# 数据与隐私

## 公开内容

公开源码包含程序、数据库建表脚本、测试代码及12道虚构演示题。演示题没有真实学校、教师、学生、原卷、联系方式或AI调用记录。

## 本机生成的私有内容

- `data/`中的SQLite数据库、运行锁和`private/`凭据。
- `sources/`原卷，`assets/`截图，`imports/`导入记录。
- `releases/`讲义、题目快照，`backup/`完整备份。
- `build/`构建及文档缓存，`output/`其他生成物。

以上内容已加入忽略规则，并且不在源码打包白名单中。不要使用“压缩整个文件夹”或界面的“完整备份”作为公开发行包；使用 `python scripts/package_public.py`。

## 密钥

源码包不含任何API密钥或本机加密凭据。`.env.example`只有空值说明，程序不会自动加载.env文件。环境变量由使用者设置。源码中的隐私测试使用虚构哨兵值，不可作为服务密钥。

## 发布检查

打包器检查候选公开文件中的密钥格式、个人主目录路径、会话令牌、邮箱、手机号码与身份证样式文本；发现命中时只报告文件和规则，不打印敏感值。自动检查不能判断所有自然语言中的人名，因此新增文档、图片或教学材料仍需发布者检查。原始图片、PDF和数据库默认不进入源码包。

本服务为单机工具，仅监听回环地址，不提供面向公网的账户和权限系统。
