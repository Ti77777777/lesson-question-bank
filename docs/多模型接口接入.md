# 多模型接口接入

## 支持范围

系统提供四种请求与返回格式适配，模型ID可自定义，不把接口锁定在某一型号。

| 协议 | 适用入口 | 图片与结果处理 |
|---|---|---|
| OpenAI Chat Completions兼容 | DeepSeek、通义千问、硅基流动、其他兼容网关、Ollama、LM Studio | data URL图片；choices/message返回 |
| OpenAI Responses | OpenAI及兼容Responses的服务、Azure OpenAI v1 | input_image；读取output_text；关闭服务端store |
| Anthropic Messages | Claude及Messages兼容网关 | base64 image source；读取text内容块 |
| Gemini原生generateContent | Google Gemini及兼容网关 | inlineData图片；读取非thought文本parts |

选择“自定义”后可自行修改协议、Base URL、模型和认证方式；例如接入智谱、Moonshot、火山方舟、OpenRouter或私有部署。它们是否支持图片、JSON参数、所选模型及区域，需要用实际账号验证；预设或兼容声明不等于所有模型都具备同样能力。AWS Bedrock的签名鉴权、Vertex OAuth等特殊认证并未直接实现，可通过兼容网关接入。

## 配置步骤

1. 在“AI工作台 → 模型与接口设置”选择预设，核对Base URL与账号地区。地址不包含末尾的`chat/completions`、`responses`、`messages`，也不包含密钥查询参数。
2. 填写模型ID，或先保存接口设置、读取模型列表后选择。部分网关不提供列表，允许手动填写。
3. 配置API密钥。Windows使用当前用户DPAPI加密保存；其他系统使用界面显示的环境变量名。系统不会自动加载`.env`文件。
4. 核实输入、输出单价，单位均为人民币/百万tokens；其他币种须自行换算。非DeepSeek云端预设不猜测价格，留空时禁止开始付费任务。DeepSeek预填值沿用旧配置，使用前也应核实。免费本地服务可填0。
5. 勾选该模型实际支持的图片能力。纯文字模型可处理无图文本题，不能直接导入PDF或图片。
6. 先验证文字与JSON，再验证图片。验证成功后再上传少量试题，检查识别、解答与分类效果。

模型列表读取只发GET请求，不生成内容。文字与图片验证会发生成请求，可能计费；只使用系统合成的内容，图片为简单算式，验证其答案。验证预留按所填价格估算不超过1元，实际账单由服务商计算。测试调用单独返回用量和费用估算，不计入试卷批次预算。验证通过不保证复杂数学题的识别或解答正确。

## 兼容参数

- 部分Chat接口不支持`response_format`，可关闭“JSON输出参数”；提示词仍要求JSON，返回后继续严格解析。
- 部分OpenAI Chat模型使用`max_completion_tokens`，可在高级设置切换。Responses、Claude和Gemini分别使用自身长度字段。
- 默认不发送跨服务商的推理参数。DeepSeek可使用专用thinking开关；OpenAI可选reasoning参数。模型不支持时请改为默认行为。
- 原生Claude与Gemini自动使用各自密钥请求头，普通兼容接口使用Bearer。Azure等可选择`api-key`请求头；本地无认证服务可选“不需要密钥”。
- 云端须使用HTTPS；本机localhost、127.0.0.1、::1可用HTTP。系统保持TLS证书验证，不将密钥转发到重定向地址。

参数不兼容会给出诊断，不会悄悄切换模型、服务商或重复发送已可能计费的请求。

## 凭据、任务与费用

不同服务地址的加密密钥分别保存，切换地址不会自动套用原地址密钥。页面和接口不回显已保存密钥，公开打包排除全部私人数据库及凭据。

新批次保存协议、地址、模型、参数与单价快照；之后修改全局设置，已有任务继续使用原配置。要更换服务商处理同一份材料，应建立新任务。缓存指纹包含连接设置与图像内容，避免跨模型误用结果。

预算是基于所填单价、输入规模与最大输出长度的保守估算，并非服务商账单。无用量、超时或中断时保留未知费用的预留；不会声称未计费。原生Gemini计入返回的思考tokens，Claude缓存输入按所填输入单价估算，缓存及图像的实际价格可能不同。
