# AI工作台

1. 安装可选PDF/图片依赖，在工作台输入自己的密钥。Windows本机保存使用当前系统账户的加密保护；其他系统可设置环境变量。
2. 上传自己有权处理的PDF或图片，设置目标学生和本批预算。
3. AI依次识题、重录分离题面、独立解题、对照参考答案复核，再给出标签和难度建议。
4. 查看原卷及截图。题面不全、包含答案或题号不对应时，使用“手动指定题面”重新框选；保存不会直接触发收费处理。
5. 检查候选，按需采纳。AI自复核与教师审校分别记录，仍需检查数学正确性。

暂停会在请求返回后生效；继续时复用已完成步骤。连接中断可能产生费用但没有拿到结果，系统会保留未知费用预留并计入预算。只有明确重试才会对失败结果重新请求。

## 数据范围

发送内容包括处理中的题面图片、题目文字及复核所需参考答案；私有原卷、响应、截图、费用和审校记录保存在本机。源码演示不包含这些运行记录，未配置密钥时不会自动发起模型请求。
