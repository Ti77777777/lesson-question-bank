# 题目纠错

## 从检索结果发起

每道检索结果右侧增加“纠错”按钮。点击后可选择问题类型，填写问题说明和修改建议。支持题干与选项、答案、解析与解答、图片与公式、知识点与方法标签、试卷来源与年级、难度与评分，以及其他问题。

记录会关联发现问题时的题目版本。即使题目随后产生新版本，原来的问题说明仍然保留。相同版本下完全相同的待处理记录重复提交时，返回已有记录。

## 修改与处理

1. 点击“打开题目修改”，进入以当前版本为基础的新建版本表单，可修改题型、题干、选项、答案和整题解析。解法和标签可通过题目详情中的相应操作处理；试卷名称、考试类别和年级在 AI 工作台的“试卷来源”中修改。
2. 保存修订说明与新版本后，在题目详情点击“纠错与处理记录”。
3. 核对完成后选择“标记已修正”，填写处理说明，可关联实际修订版本。来源、标签或难度等调整可不关联版本，但应在说明中写清调整内容。
4. 若确认原题无误，选择“无需修改”并填写判断依据。后续发现仍有问题时，可“重新打开”。

每次状态变化都保留在“处理过程”中。登记或处理纠错本身不会修改题目内容、自动调用 AI 或代替审校；保存新题目版本沿用原有重新审校规则。

## 集中查看待处理问题

检索结果区增加“仅看待纠错”，可与来源、年级、知识点、题型等条件组合。题目卡片显示待处理数量；按钮旁的数字是全部纠错记录数，包含已处理记录。

旧版本上尚未处理的记录仍计入待纠错，避免新建版本后遗漏问题。提交和处理记录时保留当前筛选与已加载的检索结果。

## 接口

- `GET /api/questions/{qid}/corrections`：获取题目版本列表、纠错记录、逐条处理过程及待处理数量。
- `POST /api/questions/{qid}/corrections`：提交 `version_id`、`category`、必填 `description`、选填 `suggestion`。说明与建议各最多 5000 字。
- `PATCH /api/corrections/{cid}`：提交 `status`（`pending` / `resolved` / `dismissed`）、必填 `note`、`expected_status`；已修正时可提交同一题目的 `fixed_version_id`。状态已经变化时返回 409，防止旧页面覆盖新处理。
- `GET /api/questions?correction=pending`：仅检索存在待处理纠错的题目。每条结果新增 `version_id`、`correction_count`、`correction_pending`。
