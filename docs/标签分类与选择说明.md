# 标签分类与选择

更新日期：2026-10-27

## 类别与主题

标签采用两级浏览：先选择维度，再选择该维度下的主题。检索页使用常驻左侧栏，新建题目和题目详情使用分类弹窗。当前 160 个有效标签均保留可选入口。

| 类别 | 当前标签数 | 当前浏览主题示例 |
| --- | ---: | --- |
| 知识点 | 36 | 集合、常用逻辑用语、不等式、函数与导数、模型与应用 |
| 解题方法 | 41 | 图形与直观、分类与分段、特值与反例、换元与代数变形、区间与函数分析、元素分析与计数、逻辑推理 |
| 数学思想 | 16 | 转化与化归、数形结合、数学建模、最值与等号、结构与计数 |
| 前置知识 | 18 | 集合、不等式、函数与导数、方程与代数基础 |
| 易错点 | 38 | 逻辑与否定、空集与边界、条件与定义域、等号与最值、集合概念与关系、运算与符号、建模与单位 |
| 教学用途 | 10 | 诊断与辨析、基础与巩固、综合与迁移、应用与建模、教学范围 |
| 教材位置 | 1 | 必修第一册 |

主题根据现有标签名称生成，用于整理浏览；已有的同维度父级关系优先。未匹配规则的新标签保留在相应“其他”主题，未知维度保留“其他标签”入口。停用和已合并标签不列入候选目录。

分类导航的数字表示标签数，不表示题目数。知识点和前置知识中同名标签保留各自角色和 ID；选择父级标签也不会自动选中其子标签。

## 操作方式

- 默认打开知识点；可切换解题方法、数学思想等类别，或选择“全部”。
- 搜索匹配当前类别的标签名称、说明和主题。需要跨类搜索时先选择“全部”。
- 可跨类别多选，上方汇总已选标签并标注类别。切换类别、主题或搜索不会丢失选择。
- “只看已选”用于核对当前类别的选择；配合“全部标签”可查看全部已选项。
- “显示说明”按需展开原有说明；默认收起长说明，便于快速浏览。
- 检索页直接勾选即时筛选，可在侧栏或右侧已选条件中移除标签。匹配方式在侧栏选择“同时包含”“任一包含”或“排除所选”。
- 桌面左侧栏随页面滚动保持可见，题目结果位于右侧；宽度不足 1000px 时变为页内可展开区域，无须打开弹窗。刷新保留检索标签与匹配方式。
- 新建题目和题目详情的弹窗仍在确认后提交选择，取消保留原选择。

同一个选择器也用于新建题目、题目详情添加标签，分类方式保持一致。

## 验证
