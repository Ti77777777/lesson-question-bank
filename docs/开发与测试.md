# 开发与测试

## 目录

- `app/`：HTTP接口、SQLite访问、AI流水线、网页和讲义导出。
- `data/schema.sql`：业务结构；`data/seed.py`：虚构演示数据生成器。
- `examples/demo.json`：12道演示题，四种题型各3道。
- `templates/exbook/`：保留原作者信息的MIT许可模板。
- `tests/`：功能回归测试，使用临时测试库。
- `scripts/`：测试、审计、通用TeX导入与开源打包工具。

## 回归测试

```sh
python scripts/test_backend.py
node scripts/test_frontend.mjs
```

每个Python测试模块使用独立进程，避免数据库配置在模块加载时相互影响。测试不调用收费AI接口，AI结果与网络故障均用模拟响应验证。完整编译验收单独运行 `python tests/test_flow.py`，需要本机TeX环境。

## 演示数据库

`python run.py --demo`首次启动会自动生成。也可运行 `python data/seed.py --database build/my-demo.db`。生成器拒绝覆盖已有数据库；需要重复测试时使用新的临时路径。

## 开源包

```sh
python scripts/package_public.py --check
python scripts/package_public.py --output dist/question-bank-source.zip
```

打包时记录每个公开文件的SHA-256和大小，不记录工作站绝对路径、用户名或私有数据库统计。现有输出文件不会被静默覆盖。
