# 模板接口 v1

> 对象：`templates/exbook/ExBook.cls`（`\fileversion` 1.2，`\filedate` 2026/10/27，见 `ExBook.cls:1`–`ExBook.cls:2`）。本文件只记录**已经存在**的接口，出处均给行号，便于模板升级时逐条核对。凡模板没有的能力，写在“已知限制”里，不在此处虚构。

## 0 使用边界

题库不保存导言区。题目记录只有数学内容与少量结构字段，文档类的选项、字体、页面几何、封面文字全部由构建程序按题单生成。生成顺序是：快照 → `config.tex`（变量赋值）→ 正文 `.tex`（`\section` 与 `qitems`）→ 用 `ExBook` 类编译。

`ExBook.cls` 顶部注释声明“用户配置通过 config.tex 中的 `\XXX{...}` 命令完成，这些命令将值存入 `\ExBook@value@XXX` 宏”（`ExBook.cls:15`–`ExBook.cls:16`）。仓库当前只有 `templates/exbook/contents/` 下的两段现成页面，没有 `config.tex`；`config.tex` 由构建程序生成，内容即第 2 节的变量赋值。

## 0.1 本地覆写层（重要）

`templates/exbook/ExBook.cls` 在文件末尾追加了一层覆写，用「后定义覆盖前定义」的方式生效，**不删除上游的任何定义**，因此下面按行号引用的接口仍然有效。这一层是为「习题课讲义」而非「刷题本」做的：

| 改动 | 具体 |
|---|---|
| 封面 | 极简白底：只有标题、副标题、作者、日期；不排封面图、前置语、座右铭、版式标签与装饰线 |
| 章节标题 | 左对齐加主题色短线；不再每节 `\newpage`，改用 `\needspace{7\baselineskip}` 防止标题落在页底、题组不再每题强制换页 |
| 题号 | 主题色加粗、悬挂缩进 1.95em，长题干折行后与正文对齐 |
| 小问与选项 | 小问缩进 2.7em 与题干文字对齐；选项块整体右移 0.65em 并等量缩减表格宽度 |
| 解析框 | 浅底细左线；框内用 `\analysispart{解析}`、`\analysispart{答案}` 分段，解析在前、答案在后；长解析可跨页 |
| 新增命令 | `\answerspace{N}` 学生版书写区；`\hinttext{…}` 学生版提示行 |
| 页眉页脚 | 左为 `\PreTitle`（班级 · 专题），中为 `\Lhead`（讲义标题），右为 `\Rhead`（学生版 / 解答版 / 解析版）；页脚「第 N 页 / 共 M 页」 |

覆写层的实现位置为 `ExBook.cls` 第 1417 行起（`\AtBeginDocument` 之后、`\endinput` 之前），共六节：封面、章节标题、题目、解析框、作答区与提示、页眉页脚。追加不改变前 1415 行的任何行号，所以下文按行号引用的出处仍然有效；新增命令不在此前出现。

升级上游 `ExBook.cls` 时：保留末尾覆写层，把新版 cls 的 `\endinput` 之前内容整体替换，再重跑一次双版本编译，核对封面、题号、解析框、页脚四处。覆写层依赖的宏名（`\PreTitle`、`\qitem`、`analysis`、`qitems` 的 `showanalysis` 键）若在新版改名，必须在覆写层同步。

`template_hash()` 记录的是覆写后 cls 的校验值，发布物据此可判断当时用的是哪一版模板。

## 0.2 开源构建的图片配置

下文记录上游模板的能力和默认值，不代表题库当前启用的配置。当前生成器不写入 `\CoverImg` 和 `\WaterImg`，不要求封面图或水印图存在。`COVER_FILE`、`WATER_FILE` 名称保留给历史发布重建与可选附件归档，不能作为干净源码构建的必备文件。

## 3 正文宏

### 3.1 题目与解析

| 名称 | 类别 | 签名 | 作用 | 出处 |
|---|---|---|---|---|
| `\section` | 命令 | `\section{标题}` | 分节标题，样式在 §7 的 `\titleformat` 中定义，自带 `\newpage` | `ExBook.cls:1349`、`ExBook.cls:1399` |
| `qitems` | 环境 | `\begin{qitems}[键值] … \end{qitems}` | 题号计数器的作用域，一次连续编号的题目组 | `ExBook.cls:1012`–`ExBook.cls:1046` |
| `\qitem` | 命令 | `\qitem[前缀][后缀附加]` | 递增题号并输出编号，可带两个可选参数；覆写层把题号改为主题色加粗并悬挂缩进 1.95em | `ExBook.cls:1049`–`ExBook.cls:1057` |
| `analysis` | 环境 | `\begin{analysis}[标签文字] … \end{analysis}` | 解析块；关闭时把内容吸入 `\box0` 丢弃，不占版面 | `ExBook.cls:1061`–`ExBook.cls:1113` |
| `solution` | 环境 | `\begin{solution} … \end{solution}` | 带框解答块，由 `\setSolutionDisplay` 控制显隐 | `ExBook.cls:277`–`ExBook.cls:318` |
| `subqitems` | 环境 | `\begin{subqitems} … \end{subqitems}` | 小问列表，一级 `(1)`，二级 `(i)`；覆写层设 leftmargin 2.7em / 4.6em，使括号与题干文字对齐 | `ExBook.cls:1117`–`ExBook.cls:1119` |
| `\subqitem` | 命令 | `\subqitem` | 等价于 `\item` | `ExBook.cls:1122` |
| `\setSolutionDisplay` | 命令 | `\setSolutionDisplay{\showSolution}` 或 `{\hideSolution}` | 打开或关闭 `solution` 环境 | `ExBook.cls:175`–`ExBook.cls:189` |
| `\qanswerloc` | 命令 | `\qanswerloc{页码}` | 印一行“此部分答案见原书 Pn”，主题色带圈箭头 | `ExBook.cls:266`、`ExBook.cls:268` |

`analysis` 的括号参数是块首的标签文字，默认“解析：”，可以改成“解：”“答案：”或“易错点：”（`ExBook.cls:1061`、`ExBook.cls:1099`）。关闭时内容进入 `\setbox0=\vbox\bgroup`（`ExBook.cls:1104`），所以块内的 `\label`、计数器改动仍然执行，但不出现在页面上。

覆写层把 `analysis` 重画成「浅底 + 2.4pt 主题色左竖线 + 顶部标签」的块，括号参数留空时标签显示“解答”；框内 `\parskip` 设为 0.6mm，使“答案”与“解法”两段自然分开。生成器传空参数（`\begin{analysis}[]`），正文首行自己写加粗的“答案：”。

### 3.2 选项排版

| 名称 | 签名 | 作用 | 出处 |
|---|---|---|---|
| `\fourchoices` | `\fourchoices{A项}{B项}{C项}{D项}` | 四个选项，按最长项自动排 4 列、2 列或 1 列 | `ExBook.cls:1179`–`ExBook.cls:1217` |
| `\threechoices` | `\threechoices{A项}{B项}{C项}` | 三个选项，同上 | `ExBook.cls:1141`–`ExBook.cls:1176` |
| `\fivechoices` | `\fivechoices{A}{B}{C}{D}{E}` | 五个选项 | `ExBook.cls:1220`–`ExBook.cls:1261` |
| `\sixchoices` | `\sixchoices{A}{B}{C}{D}{E}{F}` | 六个选项 | `ExBook.cls:1264`–`ExBook.cls:1307` |

分列阈值是选项最长宽与行宽的比较：大于 `0.4\linewidth` 纵排，大于 `0.2\linewidth` 双列，否则四列（`ExBook.cls:1126`–`ExBook.cls:1131`）。覆写层在四个命令外再包一层 `\ExBook@choiceswrap`：整块右移 0.65em，同时把 `\linewidth` 等量减掉，总宽不变；`arraystretch` 同时收到 1.15。这正是大纲 §12.2 “四个选项都能放下时排成一行并均匀分布，否则全部纵排”的实现。选项前缀后缀取 `\@optprefix` 与 `\@optsuffix`，由 `qitems` 的 `optprefix`、`optsuffix` 键设置（`ExBook.cls:1007`–`ExBook.cls:1008`），默认前缀空、后缀为句点。

## 4 题号与开关

### 4.1 qitems 的键

| 键 | 默认 | 作用 | 出处 |
|---|---|---|---|
| `startnum` | `0` | 起始题号，实际把计数器置为 `startnum` 后再减 1，使第一题编号为 `startnum` | `ExBook.cls:1009`、`ExBook.cls:1034`–`ExBook.cls:1039` |
| `unreset` | 假 | 不把题号计数器归零，接着上一组继续编号 | `ExBook.cls:1002`、`ExBook.cls:1016`–`ExBook.cls:1018` |
| `unshow` | 假 | 不显示题号（题号位置仍占位） | `ExBook.cls:1003`、`ExBook.cls:1052`–`ExBook.cls:1056` |
| `showanalysis` | 假 | 打开解析显示；只有“打开”，没有对应的关闭键 | `ExBook.cls:1004` |
| `prefix` | 空 | 题号前的固定文字 | `ExBook.cls:1005`、`ExBook.cls:1020` |
| `suffix` | `.` | 题号后的固定文字 | `ExBook.cls:1006`、`ExBook.cls:1023` |
| `optprefix` | 空 | 选项字母前的文字 | `ExBook.cls:1007`、`ExBook.cls:1027` |
| `optsuffix` | 空 | 选项字母后的文字 | `ExBook.cls:1008`、`ExBook.cls:1030` |

`\qitem` 的两个可选参数分别落在题号前后（`ExBook.cls:1053`）：`\qitem[例][：]` 在 `prefix` 空、`suffix` 为 `.` 时输出“例1.：”，标点紧贴题号。要得到干净的“例1”，应设 `\begin{qitems}[suffix={}]` 再写 `\qitem[例]`。

覆写层把每组 `qitems` 的键值先复位再解析：`prefix` 空、`suffix` `.`、`startnum` 0、`reset` 与 `show` 打开。上游实现把这些值留在宏里，上一组用了 `unshow` 或 `prefix={例}`，下一组会继续沿用；讲义里一组例题、一组练习常各自编号，所以改成组内有效。`unreset`、`unshow` 的开关状态也在环境结束时恢复。

### 4.2 与解析显隐有关的两套机制

| 机制 | 打开方式 | 关闭方式 | 出处 |
|---|---|---|---|
| `analysis` 环境 | 文档类选项 `analysis`，或 `qitems` 的 `showanalysis` | 都不给即关闭 | `ExBook.cls:56`、`ExBook.cls:1004` |
| `solution` 环境 | `\setSolutionDisplay{\showSolution}` | `\setSolutionDisplay{\hideSolution}` | `ExBook.cls:179`–`ExBook.cls:189` |

两套机制互不相干。同时使用时可能出现“解析显示了、解答框没显示”，构建程序只选一套：题库的解析统一走 `analysis` 环境，教师版的“解答”也写成 `\begin{analysis}[解：]`，不调用 `solution` 环境。

## 5 一道题如何落到 LaTeX

下表是 `app/latex/exbook.py` 的实际输出，不是设想。改生成器时先改这张表，再改代码。

| 题库字段 | 实际输出的 LaTeX | 备注 |
|---|---|---|
| `collection_section.title` | `\section{函数的单调性}` | 模板的 `\section` 自带分页 |
| `section.kind = concept/summary/note` | 只出 `\section{}` 与 `section.intro` | 不进 `qitems`，不占题号 |
| 一组题目 | `\begin{qitems}[startnum=N]`，教师版加 `showanalysis` | 环境结束强制 `\clearpage`（`ExBook.cls:1045`），故一个分节一页 |
| `item.role` | 不参与排版 | 题号全篇连续，角色只用于组题检查与界面显示 |
| `item.required = 0` | 题干前显示「（选做）」 | 学生版与教师版一致 |
| `question_version.stem` | 直接写在 `\qitem` 之后 | `____`、`\blank` 统一成 `\blankline`；`（\blankbox）` 收成 `\blankbox` |
| `qtype = single/multi` 且 4 个选项 | `\fourchoices{a}{b}{c}{d}` | 3 个用 `\threechoices`；其他个数逐行 `A.~…` |
| `answer_keys` | 教师版答案行：`答案：A`，多选 `答案：A、C` | 选项 `key` 稳定，显示时才映射 A/B/C/D |
| `subquestions` | `\begin{subqitems}\subqitem …\end{subqitems}` | 编号自动 `(1)(2)` |
| 小问答案 | 仅当整题 `answer` 为空时补「小问答案：（1）…；（2）…」 | 整题答案已写完则不重复 |
| `solutions` | 同一 `analysis` 框内逐条：`\textbf{解法一 判别式法}\par <步骤>` | 只输出 `solution_id` 指定的那条，为空则全部；标签里的空格转控制空格，否则被 xeCJK 吞掉 |
| `solution.conditions` | 步骤后紧跟「（适用条件：…）」 | 空则不出 |
| `question_version.analysis` | 无解法时作为解析正文 | 有解法时不输出，避免重复 |
| `teaching.why/key_step/pitfalls/probe` | 教师版末尾一行「为什么想到…／关键一步…／易错点…／追问…」 | 选项 `teacher_notes=false` 可整块关掉 |
| `hint_level = keyword` | 学生版 `\hinttext{…}`，取 `key_step` 第一个不在公式内的句读，最长 24 字 | 截断点必须落在 `$…$` 之外，否则会出现未配对的 `$` |
| `hint_level = method/full` | 学生版 `\hinttext{…}`，取 `key_step` / `probe`，最长 60 字 | 同上 |
| `material_refs` | `\imgin[0.5]{}{assets/…}` | 文件不存在时跳过，不报错 |
| `space_mm` | 学生版 `\answerspace{N}` | 左侧淡色竖线标书写区；教师版不留白 |
| `item.page_break_before = 1` | `\clearpage`（首条不加） | 放在 `\qitem` 之前 |
| `item.points` | 非空时题干后显示「（N 分）」 | 是否计分由题单条目明确设置，支持零分 |
| `collection.purpose` | 只影响封面副标题与页眉 | 模板无答题卡版式 |

题号、顺序、小问编号两版必须一致，所以正文由同一个循环生成，只切换「是否渲染答案类节点」。学生版防泄露靠结构保证（源码里根本不写答案），生成后再按答案首 16 字回扫一遍源码复核。

## 6 生成器的真实接缝

`app/latex/exbook.py` 是「题库数据 → LaTeX 源」的纯函数层，`app/latex/build.py` 负责取快照、落盘、编译、校验与登记。两者之间的函数签名就是新增模板时要实现的最小接口，以代码为准（本节与代码同步，行号会漂移，函数名不会）。

### 6.1 四个函数

```python
def normalise_options(options: dict | None, collection: dict | None = None) -> dict
def render_body(snapshot: dict, options: dict, version: str,
                available: set[str] | None = None) -> str
def render_document(snapshot: dict, options: dict, version: str,
                    body: str | None = None,
                    available: set[str] | None = None) -> str
def template_hash() -> str
```

- `normalise_options` 补齐缺省值。缺省标题取题单 `title`，`format` 取 `standard`，`theme` 取 `blue`，`creator` 取「示例教师」，`versions` 取 `["student", "teacher"]`。
- `render_body` 产出「从第一个 `\section` 到正文结束」的片段，不含导言区。
- `render_document` 产出完整可编译文档：`\documentclass` + `config.tex` 的内容 + `\begin{document}` + 封面 + 正文。
  `version` 取 `student` 或 `teacher`；`body` 传入时直接用它，否则内部调 `render_body` 生成。
- `template_hash` 返回 `ExBook.cls` 的 sha256 前 12 位，写进快照与发布物，用于以后核对模板是否换过。

### 6.2 快照结构

`release.snapshot` 自足：重建时只读它，不回查题目最新版本。

```json

  "sections":   [{"id": "SEC000001", "title": "一、例题", "kind": "question", "intro": "…", "order_no": 0}],
  "items":      [{"id": "ITM000001", "section_id": "SEC000001", "question_id": "Q000001",
                  "question_version_id": "QV000001", "role": "example", "order_no": 0,

                  "page_break_before": 0, "subq_keys": null, "note": null}],

                             "version":   {"qtype": "solve", "stem": "…", "answer": "…",
                                           "options": null, "answer_keys": null,
```

题面、答案、解法都是题库里的 LaTeX 原文，生成器不做数学转义，只做三件排版处理：把 `____` 与 `\blank` 统一成 `\blankline`，把 `（\blankbox）` 收成 `\blankbox`（宏自带括号），把两个汉字之间会被 xeCJK 吞掉的半角空格换成控制空格。

### 6.3 三个版本的差别

| 差别 | 学生版 `student` | 解答版 `answer` | 解析版 `teacher` |
|---|---|---|---|
| `qitems` 环境 | `[startnum=N]` | `[startnum=N, showanalysis]` | `[startnum=N, showanalysis]` |
| 正文 | 题面 + 提示 + 作答留白 | 题面 + 一个 `analysis` 块 | 题面 + 一个 `analysis` 块 |
| 解析 | 不写 | 不写 | `\analysispart{解析}` + 解法步骤、适用条件、讲评 |
| 答案 | 不写 | `\analysispart{答案}` + `answer`、小问答案 | 同解答版，排在解析之后 |
| 提示 | 按 `hint_level` 用 `\hinttext{…}` 输出 | 不输出 | 不输出 |
| 文档类选项 | — | 加 `analysis`，主文件定义 `\qbAnswerVersion` | 加 `analysis`，主文件定义 `\qbTeacherVersion` |

题号、顺序、小问编号必须完全一致，因此三版共用同一份 `render_body` 循环，只切换「渲染到哪一段」。

## 7 新增一种模板

把 `templates/<name>/` 放好类文件，在 `app/latex/` 下新增一个模块实现 §6.1 的四个函数，然后在 `build.py` 里按 `options["template"]` 分派。约束：

1. **纯函数**：只读入参，不写文件、不连数据库、不调编译器；落盘与编译归 `build.py`。
2. **确定性**：同一快照与选项必须产出相同字符，不写当前时间、不用随机数、不依赖字典遍历顺序。
3. **不越界**：不生成声明页、广告页一类固定内容。
4. **素材路径**：`\imgin` 用相对 `build_dir` 的路径，复制由 `build.py` 的 `asset_targets()` 负责。
5. **失败明确**：缺字段时抛异常并用中文说明缺在哪一条，不静默跳过。
6. **能力下限**：分节、连续题号、可控起始题号、选项自动排版、解析显隐、小问、条目留白、封面标题与页眉文字，八项缺一不可。

## 8 已知限制

| 限制 | 表现 | 出处 | 规避 |
|---|---|---|---|
| 解析显隐是双开关 | 文档类 `analysis` 给初值，`qitems` 的 `showanalysis` 只能打开、不能关闭；一旦全局打开，无法在某组内关掉 | `ExBook.cls:56`、`ExBook.cls:1004`、`ExBook.cls:1063` | 学生版不加 `analysis` 选项，也不写 `showanalysis`；教师版整体打开 |
| 两套解答机制并存 | `analysis` 与 `solution` 各自受不同开关控制，混用会出现解析可见而解答框不可见 | `ExBook.cls:277`、`ExBook.cls:1061` | 统一用 `analysis`，不调用 `solution` |
| 模板不自带声明页 | 仓库里的 `contents/pre.tex` 是 ExBook 项目的考研声明，含公众号与“此刷题本不包含答案”，与校内讲义不符 | `templates/exbook/contents/pre.tex:1`–`24` | 不要 `\input{contents/pre.tex}`；`contents/print.tex` 同理 |
| 节标题与首题的间距由 `\needspace` 守卫 | 页底余量不足 7 行时整节推到下页，该页会留白 | 覆写层 | 留白正好作为作答区；要强制分页仍可在节前写 `\newpage` |
| 单题版对题库生成无效 | `single`、`padl`、`padp` 的「每题一页」由 `bbox` 结束时 `\newpage` 实现，而生成器只发 `qitem`、不发 `bbox`，故 `format=single` 仍按 `standard` 连续排 | `ExBook.cls:695`、`ExBook.cls:809`、`ExBook.cls:972`；`app/latex/exbook.py` 的 `_item_block` | 需要单题分页时在条目上置 `page_break_before`，由生成器写 `\clearpage` |
| 固定底部留白 | `standard` 每题后 2.5 cm，`loose` 7.5 cm，`compact` 无；三者都不读条目里的 `space_mm` | `ExBook.cls:526`、`ExBook.cls:744`、`ExBook.cls:467` | 条目级留白由生成器写 `\answerspace{…}`，不再用 `\vspace*` |
| 空位宽度写死 | `\blankline` 3 em，`\blankbox` 1.5 em | `ExBook.cls:270`、`ExBook.cls:272` | 长空位改用 `\underline{\hspace{…}}` |
| 插图只按比例缩放 | `\imgin` 默认 `scale=0.38`，不设最大宽度，宽图会溢出到页边 | `ExBook.cls:330`、`ExBook.cls:346` | 构建时按图宽选缩放系数，或改用 `width=\linewidth` 的自定义命令 |
| 题号计数器全局唯一 | 只有 `QuestionCounter` 一个计数器，多节靠 `unreset` 续号，无法同时维护两套独立编号 | `ExBook.cls:992`、`ExBook.cls:1016` | 一份文件只维护一套编号；答案版单独编号 |
| `\qitem` 只有两个可选参数 | 前缀与后缀附加位各一个，多于两级标记要自行拼进字符串 | `ExBook.cls:1049` | 复杂标记写进 `prefix` 键 |
| 小问只有两级 | `subqitems` 只定义两级，第三级无默认标签 | `ExBook.cls:1117`–`ExBook.cls:1119` | 三级以下改用 `enumerate` 手工编号 |
| 页脚无自定义位 | 页码固定居中，`showmark` 只能放节标题 | `ExBook.cls:449`、`ExBook.cls:450` | 班级、日期拼进 `\Chead` |
| 字体集依赖系统 | `windows` 需要本机装宋体、黑体、楷体，缺字时编译中断 | `ExBook.cls:25`、`ExBook.cls:79` | 本机用 `windows`，其他环境用 `fandol` |

模板升级时，先比对 `\fileversion` 与 `\filedate`（`ExBook.cls:1`–`ExBook.cls:2`），再按本文件的出处逐条核对；行号变动而命令名未变的，改行号即可，命令被删改的要在本节登记。

## 10 快照与历史依赖

2026-10-27 起的新快照按版本 ID 保存条目内容，同一题目在同一讲义引用多个版本时分别渲染。旧快照缺失所需版本时明确报告，不读当前题库补造历史内容。

新发布物除源码和 PDF 外，保存实际使用的模板类、模板图片、题目配图和文件校验清单。重导优先从历史发布目录复制这些文件；旧发布物未归档模板时会提示改用当前模板，不能承诺版式与旧文件完全一致。记录文件校验值并不等于已完成完整备份恢复。
