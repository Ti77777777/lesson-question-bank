# 数学书写与显示规范

## 正确书写

| 内容 | 推荐写法 | 说明 |
|---|---|---|
| 一阶导数 | `$f'(x)$` 或 `$f^{\prime}(x)$` | 不写成 `$f\prime(x)$`，否则 prime 会落在基线上 |
| 二阶导数 | `$f''(x)$` 或 `$f^{\prime\prime}(x)$` | 导数符号为上标 |
| 数值与符号 | `极大值为 $2$，极小值为 $-2$` | 数值和负号一起使用数学模式 |
| 区间 | `$(-\infty,-1)$` | 逗号、端点与无穷符号放在同一公式中 |
| 变量 | `求 $a$ 的取值范围` | 避免正文直立字母与公式斜体字母混用 |
| 分式、根式 | `$\frac{5}{14}$`、`$\sqrt{5}$` | 显式分组，减少歧义 |
| 正文标点 | `在 $(-1,1)$ 上递减；……` | 中文标点置于公式外，必要时放进 `\text{}` |

中文正文与数学字体各自保留适当字形，统一的是同类内容的字体与字号比例。页面说明、题号与选项标签不强行改成数学变量。网页公式采用 KaTeX 默认的 1.21 倍比例，补偿数学字体的字面大小，比原先 1.03 倍设置放大约 17%；不对上下标再次放大。标签库等紧凑控件保留已有局部设置；PDF 继续使用讲义模板的数学字体。

## 旧数据兼容

公共网页渲染、AI 返回值整理及 TeX 正文输出支持常见 `f\prime(x)`、Unicode prime 和数学模式内 Unicode 负号/全角运算符的保守修正。正确的 `f'(x)`、`f^{\prime}(x)`、`f^\prime(x)` 保留；正文、日期、独立的 `\prime` 以及 `\text{}` 和文字运算符中的内容不改写。

网页显示和导出兼容不回写题库，不修改历史快照。输入框仍显示原始 TeX；建议录题时直接采用规范写法，可用数学工具栏的「导数」按钮插入。

复杂下标、多层宏与自然语言中的数学含义仍需核对，不通过猜测批量加美元符号或改动变量。演示源已统一规范；已有独立演示库不会因升级被覆盖，可保留旧库后使用新的演示库路径重新生成。
