# 界面精简与功能收拢方案

日期：2026-11-01；版本：1.0；核查基线：应用 v0.9.9／`50720c8`。

状态：设计方案，尚未改动页面。依据为当前导航、页面源码及近期更新记录；本轮未进行浏览器视觉验收，也没有使用频次统计。“常用／低频”是围绕教师找题、组题、排版流程的设计判断，不能解释为已测得的使用情况。

## 1 当前目标与取舍

当前目标是精简，不增加业务功能、必填字段或管理页面。保留已有数据与工作流程，减少同时出现在页面上的选择。优先顺序调整为：必要的正确性维护 → 本文S1—S3界面收拢；原B0—B3保留为长期工作背景，不再要求逐项扩展能力。

暂停N09／E03追练扩展、N07／E04新增换题筛选、E01新导出差异机制、O04新增计划转实际自动联动、O09质量策略扩展。已有功能的修错继续处理；E02离线资源属于可靠性专项，不与本轮界面精简打包。统一编辑组件仅在减少重复维护且不扩充能力时实施。

v0.9.9已完成说明文字收拢与大字号适配，继续压缩字号或机械删除说明收益有限。v0.9.8已修复版本更新和单条撤销等问题，不沿用10月30日“四项均未修复”的旧结论；未覆盖范围仍见[功能实现与验收台账](功能实现与验收台账.md)。

### 处理方式

| 方式 | 本轮适用对象 | 实施边界 |
|---|---|---|
| 保留常驻 | 找题、选题、题单内容、排版与导出、当前保存状态 | 保留任务主线和必要上下文 |
| 条件显示 | 选题篮数量、已用信息、新版提醒、草稿恢复、错误详情 | 有内容或需要处理时显示；未选择对象不伪报“未用过” |
| 收入二级 | 名单管理、练习安排、来源管理、历史版本、技术快照 | 原能力与旧链接仍可用，入口名称明确 |
| 合并／删除重复呈现 | 两处选题篮按钮、两套导出参数、两处留白编辑、系统重复入口、全局规模数字 | 替代路径通过后才撤下旧入口；不删除业务数据 |
| 暂停扩展 | 未完成的新追练、推荐筛选、流程自动化等 | 保留设计记录，不为“清空待办”继续加功能 |

没有证据支持直接删除使用记录、教师班级、版本历史、来源、备份等业务能力。可以明确删除的是重复按钮、重复表单和不参与当前决策的常驻信息。练习安排适合降级保留，是否彻底停用需先确认实际依赖，不能因为页面拥挤就清掉记录。

## 2 导航：从7项并列改为3项主入口与“更多”

当前 `app/static/index.html` 并列显示AI工作台、收题箱、题库检索、题单、导出与归档、使用与反馈、系统，另有全局统计和选题篮。建议如下：

| 一级入口 | 默认内容 | 二级位置与旧地址 |
|---|---|---|
| 题库 | 现有题库检索 | 题目详情；来源管理移入“更多操作”；保留 `#/search`、`#/question/:id`、`#/sources` |
| 题单 | 现有题单列表 | 编辑题单 → 排版与导出；保留 `#/collections`、`#/collection/:id`、`#/layout/:id` |
| 导入 | 直接打开现有AI导入页 | 同级切换“导入试卷／手工录题／收题箱”；保留 `#/ai`、`#/question/new`、`#/inbox` |
| 更多 | 菜单，不新建汇总首页 | “讲义归档”“使用记录”“系统信息”；分别保留 `#/releases`、`#/usage`、`#/settings` |

这是既有页面重新分组，不新增“导入中心”数据层或任务列表。AI处理记录和收题箱不是同一种状态，不合并存储。导入入口保持一级可见，避免频繁导卷时增加寻找成本。

主导航的常驻项目由7个减为4个，常规目的页通过一级入口或一次菜单展开到达。编辑具体对象后的详情层级另计，不能借此堆叠多层导航菜单。默认无地址进入题库；显式旧链接和已有题单恢复优先，不能强制跳转。品牌点击回题库，“继续上次工作”移至题单列表，复用现有记录与清理规则。

移除页头题目／题单／收题箱规模数字，统计保留在系统信息页。系统信息只保留“更多”中的一个全局入口，删除重复页脚链接与无任务用途的常驻日期。选题篮在题库及读题上下文可见；其他页仅在已有待选题时显示。菜单、浏览器返回和旧书签不触发写入或AI请求。

## 3 逐页精简清单

### C01 检索：条件按任务分组，结果先露出来

源码依据：`app/static/pages/search.js`、`app/static/lib/saved-searches.js`、`app/static/lib/tag-sidebar.js`。

- 首层保留关键词、知识点／方法、年级、题型、思维难度和结果排序。来源类别、年份、地区、试卷放入一个“按试卷找题”折叠组；沿用已有更多条件，不再新增一排独立卡片。
- 教学对象、观察天数和仅看未用过收入“按使用情况筛选”；选定对象后在结果区显示对象名称及适用范围。已生效的隐藏条件继续以可移除标签显示，折叠不等于清空。
- 保留各类独立多选语义，不直接换成全局多选。入口随所在条件组显示，默认无须把所有开关摆在首屏。常用筛选方案改为紧凑选择入口，不让方案按钮不断横向增长。
- 移走“管理试卷信息”，删除页面内与全局重复的“查看选题篮”。“加入已有题单”保留为有选题时明确可用的批量操作；不靠新建目标题单状态系统实现精简。
- 结果卡保留题面、必要标签、审校状态和“加入选题篮”。标题可打开详情时，不再同时摆相同目标的“查看题目”按钮。纠错放入卡片更多操作，但未解决纠错标记继续可见并可直接打开。
- 三维难度、推荐理由、完整出处等放详情；思维难度不能改名为无来源定义的“综合难度”。缩略内容不得截断公式或遮住审校问题。

### C02 题单：负责题目内容，退出重复排版

源码依据：`app/static/pages/collection.js`、`app/static/pages/layout.js`。

- 顶部突出“排版与导出”；撤销／重做保持可见且紧凑，保留动作说明和不可用状态。“改题单信息”、归档等进入有明确名称的更多操作。
- 删除独立“快速导出”参数表单，入口若需兼容则转到当前题单排版页。先核对快速导出独有字段和版别选择：现有值原样保留，不强行映射为其他字段；必要控件可迁入排版高级区，不扩展新的参数。
- 作答留白、题前分页只在排版页编辑；题单设置保留教学角色、分节、小问／解法、用时和讲评备注。处理现有覆盖优先级后才移除旧控件，不把旧值清空或重置为默认值。
- 每条题目保留排序和“设置”；换题、移除收入条目更多操作。移除仍可撤销，换题必须保留预览版本绑定、重复拦截和完整对照，不能合成一个无确认的快捷动作。
- 组题检查常态只显示题数、时间及需处理事项，分布统计按需展开；阻断和警告继续直接呈现。不能因为没有展开检查就允许绕过导出校验。
- 新建题单先填写名称，已有用途／课时等进入可选设置；编辑时已有非默认内容用摘要可见，不能隐藏后丢失。

### C03 排版：保留纸面操作，减少重复控制

当前已收起封面署名、样式及帮助，继续沿用，不重新做一套设置面板。

- 首层保留标题、版面密度、当前题目留白／分页、预览版别与“导出”。封面、主题色、选项完整性、模板管理继续在高级区。
- 保留快速预览和PDF校样：一个用于快速调整，一个验证实际排版，二者不算冗余。保留三版文件能力，避免把“精简”误成只输出一种。
- 自动保存正常时显示状态；“立即保存”保留在更多操作，保存失败时把重试直接显示出来。离开和导出前仍需等待保存，不能简单删按钮后放任未保存内容。
- 页面缩放保持原功能；不缩小正文、公式或纸面字号来腾空间。完整题目、答案和数学表达不能因收拢控件而被截断。

### C04 题目详情：先读题，需要时再编辑

`app/static/pages/question.js` 已折叠版本、出处、关系和使用历史，不重复宣称这些是待新增的折叠能力。剩余重点是顶部六项并列动作及常驻审校编辑表单。

- “新建版本”用“修订题目”表达日常任务，仍创建版本；差异查看放版本历史中。纠错保留明确入口，有待处理项时突出显示。
- 停用、恢复和合并放“管理操作”，不与阅读动作等重；原确认、引用约束及历史记录全部保留。
- 审校摘要和未通过原因保持可见；选择结论、填写备注和提交控件在“进行审校”后展开，不改变任何审校标准。
- 选用解法默认展开，其他解法可按标题展开；存在多解、适用条件和审校问题时摘要明确显示。来源和原文证据仍从本题直接可达。

### C05 录题：减少首屏表单，不减少信息能力

`app/static/pages/question-new.js` 同时展示出处、基本信息、答案、整题解析、小问、解法、教学说明及三维评级，且“整题解析”和独立解法容易给人重复填写的印象。

- 默认顺序为题型／题干、选项与答案、解析、主要知识点、来源简要信息，再保存。来源的原文、双页码和多出处收入详细信息，来源不明仍明确标为待确认。
- 小问、另解、教学说明、三维评级与推荐依据按需展开；编辑已有内容时显示“已填写”摘要，校验失败自动展开并定位。当前必填条件不因折叠而变更。
- 采用已有整题解析作为普通录入路径，多解编辑保留在“独立解法”区域；已有结构化解法照原结构展示，不能自动拼接、删除或双写。需先核对原解法校验，不能仅隐藏仍强制必填的空解法。
- “保存后交给AI”保留为明确可选动作，勾选时费用上限、数据发送及确认信息仍可见，不放到看不见的默认设置中。

### C06 导入与AI：保留处理主线，收拢诊断与批次操作

`app/static/pages/ai.js` 已将模型设置、题号页码和来源编辑折叠。保持上传、预算、处理、进度、暂停／重试、核对采纳可见。

- 历史任务仍可选择；当前任务与待处理状态优先呈现，已完成的历史记录收入原列表的展开区，不新增任务管理模块。
- 请求次数、原始文件名、导出结果与TeX收入“处理详情／更多操作”；原卷核对、错误、预算和暂停保持就近可见。
- AI独立解答、参考答案与人工确认具有不同作用，不合并为一个“已确认答案”。不改自动入库开关含义，不减少付费确认，也不增加默认自动调用。
- 收题箱登记表改为点击“登记资料”后展开；空库时可直接展开，已有资料优先看待整理列表。手工收题与自动识别仍分开处理。

### C07 使用：记录优先，管理与计划退到二级

`app/static/pages/usage.js` 当前同时挂载名单、添加对象表单、练习安排、使用登记和已用查询；名单又包含教师管理及班级／学生／一对一切换。这是首批最值得拆开显示的页面。

- “更多 → 使用记录”默认显示实际使用列表、对象筛选和“登记使用”。反馈从对应记录进入，保留原讲义／日期／对象绑定。
- “名单管理”“练习安排”“已用题查询”作为同页二级切换，一次只展示所选区域。复用原表单和接口，不新建统计首页，也不新增权限体系。
- 添加班级／学生和新建安排表单默认不常驻，只在点击相应动作后出现。教师筛选与对象筛选保留；教师管理只在名单区域出现。
- 练习安排保留计划记录，暂停扩展自动转实际流程。已用查询与检索未用筛选用途不同，前者核查历史、后者找候选，不直接删除其中之一。
- 首期不重写两种登记表单；待核对部分使用、整份使用及重试语义一致后，才考虑复用组件，避免为了外观合并而改掉记录范围。

### C08 归档与系统：归档看文件，系统放维护

- 归档列表保留名称、生成时间、状态和文件入口；“登记使用”放记录操作，“内容快照JSON”“原快照重导”收入详情。原快照重导与当前题单导出含义不同，不能合并成无说明的同一按钮。
- 将已有备份组件从归档页面移入系统信息页，替换当前“跳到归档找备份”的间接路径。保留备份验证、恢复确认和失败说明，移位不触发备份或恢复。
- 系统信息保留库位置、模型摘要、备份及必要诊断；模型配置继续链接到已有AI设置并定位展开，不再复制一套模型表单。
- 旧归档链接、PDF文件和快照地址继续有效；去除全局规模数字不删除系统页统计。

## 4 精简规范

以下为本文验收规则S-R01—S-R08，补充[通用规范](优化规范与验收标准.md)，不改变既有R01—R16编号。

1. **S-R01 主次清楚：** 每个任务区域一个主要动作，其余用次级或菜单呈现；不把检索结果每张卡的同类动作机械计入整页上限。
2. **S-R02 最多两层导航：** 一级入口、菜单或页内二级即可找到常规功能；不要“更多 → 高级 → 其他”层层藏入口。
3. **S-R03 隐藏不丢值：** 收起表单保留草稿及已有字段，关闭弹窗不保存、不清空；重新展开恢复原值。
4. **S-R04 生效条件可见：** 被收起的筛选、非默认设置仍有摘要；错误自动定位，无结果能看出当前限制。
5. **S-R05 重要状态不隐藏：** 审校阻断、未保存、费用、版本失效、小问／解法确认和当前选中对象直接可见。
6. **S-R06 不靠缩字精简：** 保持v0.9.9字号基线；公式、题面、列表数据及纸面预览保持可读，移动端以换行和局部滚动适配。
7. **S-R07 一个设置一个编辑位置：** 同一排版参数只有一个主要编辑位置；快捷入口只导航或调用同一流程，不再存另一套默认值。
8. **S-R08 可发现也可操作：** 不用只有图标或只在悬停出现的菜单；按钮有名称，键盘可展开、Esc关闭、焦点回到触发处。需要二级内容的旧链接应直接定位对应区域。

## 5 实施顺序与验收

| 批次 | 工作范围 | 退出条件 |
|---|---|---|
| S1 导航与重复入口 | 3主入口加更多；移走全局统计与重复系统入口；检索重复按钮；详情管理操作；归档快照操作；已用页二级切换 | 原路由全部可达，无新增业务写入；主线能找到，菜单可键盘操作；表单切换不丢值 |
| S2 页面分层 | 检索来源／使用筛选、录题高级字段、AI任务详情、收题表单、名单／安排表单、题单检查摘要 | 已生效条件和非默认值可见；错误定位；旧草稿完整；没有隐藏的必填阻塞 |
| S3 合并重复实现 | 统一导出参数；题单排版字段迁移；备份组件移位；必要的同义登记组件复用 | 有效输出设置、三版PDF、历史快照、记录范围及回退通过，随后才移除重复表单代码 |

S1、S2不得顺带改质量规则、AI自动入库、数据库结构和公式样式。S3涉及输出或写入语义，必须独立提交；未核对独有参数时只迁移入口，不删除旧实现。三个批次不承诺未经估算的完成日期。

### 可核对的验收场景

| 编号 | 场景 | 通过条件 |
|---|---|---|
| S-A01 | 对照12类旧页面地址直接打开，再用新导航访问 | 均可达且高亮正确；无地址落到题库；已有明确链接不被覆盖 |
| S-A02 | 按知识点找题、选择数题、加入题单、调整留白、生成三版 | 不经过名单、计划或系统设置；内容范围、版本、顺序、留白不变 |
| S-A03 | 上传／继续既有AI任务、核对题目 | 导入一级可达；费用、暂停、错误和人工确认可见；折叠不发起模型调用 |
| S-A04 | 来源／使用筛选收起后继续找题 | 生效条件仍显示并可清除；独立多选与原结果一致；返回保留上下文 |
