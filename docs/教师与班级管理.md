# 教师、班级和学生管理

在「使用与反馈」中选择当前教师，可以集中查看他的班级、学生和一对一学生，并筛选练习安排、讲义使用记录及查询对象。选择会在当前浏览器中按题库记住。

## 开始使用

1. 点击「管理教师」，添加教师姓名或称呼，可选填工号和校区备注；「编辑资料」可修改称呼、编号和备注。
2. 选择当前教师，在右侧添加班级或学习小组。负责教师默认采用当前选择，也可暂不分配。
3. 点击班级的「查看名单」，添加新学生，或从已有学生中勾选。学生可以同时加入多个班级或小组。
4. 共同授课时，在班级的「分配教师」中勾选多位老师。学生会关联所在班级和小组的老师。
5. 一对一学生可在右侧将添加类型设为「学生」，选择负责教师；也可对已有学生直接「分配教师」。直接关联老师的学生会出现在「一对一学生」中，即使他同时有班级。

## 旧记录与调整归属

- 旧班级、学生及使用记录原样保留，不会自动猜测教师。选择「尚未分配教师」可以补充分配。
- 「学生名单」显示直接关联或通过班级关联当前老师的学生；「一对一学生」只显示直接关联的学生。
- 移出名单仅解除本班关系，学生档案、其他班级关系和历史使用记录保留。取消直接教师归属，不会取消通过班级继承的关联。
- 班级有名单关联后不能直接更改为学生，避免名单类型错乱。
- 同一份名单或教师归属被其他页面修改后，保存会提示冲突；重新打开、核对后再提交，避免覆盖他人的修改。

## 重名、编号与档案

姓名用于显示，系统编号用于关联档案。教师使用 TCH 编号，班级、小组、学生使用 AUD 编号；编号自动生成，改名不会改变编号。

| 情况 | 操作与结果 |
|---|---|
| 两位学生或教师同名 | 新建时列出已有同名档案，核对学号、工号、备注和班级。是同一人就选用已有档案；确为另一人则点击「确认不同，继续新建」 |
| 同名班级，例如不同届的高一（1）班 | 同样先核对已有档案，可填写带届别的班级代号分别创建 |
| 学号或工号尚未整理 | 可以留空。选择框仍显示唯一系统编号，稍后在「编辑资料」中补充 |
| 学号或工号重复 | 新增、修改时拦截冲突，可选用已有档案或更换编号，不能用同名确认绕过 |
| 改名或补学号 | 编辑原档案，保留系统编号、教师关系、班级关系、练习安排与使用记录 |
| 转班、退班 | 转班时从已有学生中选用同一系统编号，加入新班后再从旧班移出；退班只移出名单，保留档案和历史 |
| 请求中断后重试 | 当前页面或弹窗保留操作编号，相同内容的重试返回已创建档案，避免重复创建；刷新页面后应先检查已有档案 |

工号在教师中查重；学号、班级代号、小组代号各自在同类档案中查重。比较编号时忽略首尾空格、大小写与全角半角差异，例如 `S01` 与 `ｓ０１` 被视为同一编号。学号跨届或跨校区可能重复时，建议使用 `2027-东校区-001` 等带区分信息的代号。

名单、分配教师、使用登记、近期查询及题库检索的对象选项均显示编号；学生选项还显示所在班级。仅凭姓名不会自动合并档案。选用已有学生不会自动添加一对一教师归属，班级教师仍按班级关系关联。

升级只增加字段与操作记录表，已有档案编号不变。历史库里若已有重复代号，保留原样，不自动合并、重编号；可以先修改备注核对，再逐个更正。资料编辑也会检查是否已被其他页面修改。

## 统计口径与当前限制

教师切换只管理归属并筛选页面，**没有登录和权限隔离**，不能用来隐藏其他老师的数据。当前服务仍仅监听本机，没有加入内网部署能力。教师称呼不是审计记录中的已认证身份。

班级、学习小组和学生的题目使用记录仍分别登记，不互相继承。把学生加入班级不会把班级过去使用的题目自动登记为该学生做过；转班也不会改写历史记录。题库和题单仍共享。

本轮没有加入教师删除、批量名单文件导入或学生登录。
