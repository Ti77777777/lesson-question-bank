# 教师、班级和学生管理

在「使用与反馈」中选择当前教师，可以集中查看他的班级、学生和一对一学生，并筛选练习安排、讲义使用记录及查询对象。选择会在当前浏览器中按题库记住。

## 开始使用

1. 点击「管理教师」，添加教师姓名或称呼；也可修改称呼。
2. 选择当前教师，在右侧添加班级或学习小组。负责教师默认采用当前选择，也可暂不分配。
3. 点击班级的「查看名单」，添加新学生，或从已有学生中勾选。学生可以同时加入多个班级或小组。
4. 共同授课时，在班级的「分配教师」中勾选多位老师。学生会关联所在班级和小组的老师。
5. 一对一学生可在右侧将添加类型设为「学生」，选择负责教师；也可对已有学生直接「分配教师」。直接关联老师的学生会出现在「一对一学生」中，即使他同时有班级。

## 旧记录与调整归属

- 旧班级、学生及使用记录原样保留，不会自动猜测教师。选择「尚未分配教师」可以补充分配。
- 「学生名单」显示直接关联或通过班级关联当前老师的学生；「一对一学生」只显示直接关联的学生。
- 移出名单仅解除本班关系，学生档案、其他班级关系和历史使用记录保留。取消直接教师归属，不会取消通过班级继承的关联。
- 班级有名单关联后不能直接更改为学生，避免名单类型错乱。
- 同一份名单或教师归属被其他页面修改后，保存会提示冲突；重新打开、核对后再提交，避免覆盖他人的修改。

## 统计口径与当前限制

教师切换只管理归属并筛选页面，**没有登录和权限隔离**，不能用来隐藏其他老师的数据。当前服务仍仅监听本机，没有加入内网部署能力。教师称呼不是审计记录中的已认证身份。

班级、学习小组和学生的题目使用记录仍分别登记，不互相继承。把学生加入班级不会把班级过去使用的题目自动登记为该学生做过；转班也不会改写历史记录。题库和题单仍共享。

本轮没有加入教师删除、批量名单文件导入或学生登录。
