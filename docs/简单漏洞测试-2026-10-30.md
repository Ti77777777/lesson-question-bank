# 简单漏洞测试记录（2026-10-30）

## 范围与方法

以更新前代码为基线，在独立 SQLite 库、虚构来源文件和本机随机端口运行 HTTP 请求。没有访问外部目标系统、发送真实试卷、调用付费模型或向正式题库写入测试记录。检查文件访问、上传文件打开方式、跨站请求、错误信息、输入边界和备份导入，并核对前端公式库公开公告。

## 发现并修复

| 优先级 | 发现 | 证据与修复 |
|---|---|---|
| P1 | 来源附件可上传 HTML/SVG 等主动内容，并以原 MIME 类型在题库同源打开，存在存储型脚本执行风险 | 修复前 HTML 为 text/html 且没有下载/沙箱限制；本轮通过 HTTP 头复现，不执行窃取数据的脚本。现在主动内容与未知类型强制下载，带 sandbox、nosniff，只有 PDF、常用图片、纯文本允许内联 |
| P2 | 内部异常的类型与原文直接进入 API 响应，可能泄漏本地路径、SQL 或其他内部信息 | 用虚构异常和私有文件路径复现；现在响应只有通用消息与编号，详情只留本地日志 |
| P2 | 前端 KaTeX 固定在已被公开公告覆盖的旧版本 | 官方公告查询中 0.16.9 命中 6 条；升级至官方发布 0.19.1，加入脚本/样式 SRI 与匿名 CORS，保留 trust:false，显式限制 maxExpand 与 maxSize |

公开公告的受影响版本匹配不代表本应用中每条都可直接利用；本轮没有逐条执行公告利用代码。升级后查询未命中也不是安全保证。

## 额外加固

- Host 必须只有一个，且为回环主机名与本次监听端口；拒绝用户信息、错误端口、重复 Host 等异常形式。
- 写入请求的 Origin 必须完整匹配本机 HTTP 源；正常跨站写入已被原实现拒绝，本轮修正异常 Origin 导致断开而不是正常响应的情况。附件路径也执行同一请求校验。
- 添加 SAMEORIGIN、frame-ancestors、nosniff、same-origin 资源策略及 no-referrer，隐藏 Python 版本字符串。当前应用的本机页面和 PDF/图片读取继续可用。
- 接收请求采用 30 秒空闲超时；截断正文、非法或重复长度头、过大内容及不支持的传输编码均拒绝。
- 拒绝含控制字符的路径、超过 1000 项的查询串、非法 UTF-8/JSON、非有限数字与过深嵌套。
